# 💸 Expense Tracker with Smart Insights

A personal finance web app that tracks, categorizes, and visualizes spending, with automated analytics. Single-file, no dependencies, no backend.

## Features
- Add/delete expenses across 8 categories
- Monthly budget with progress bar
- Category donut chart and 6-month trend chart
- Smart insights: month-end projection, daily allowance, budget warnings, top category, month-over-month change, category spikes, outlier purchases, priciest weekday
- Data saved locally in your browser (localStorage)
- Light/dark mode, mobile-friendly

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Tech
HTML, CSS, vanilla JavaScript, inline SVG charts.
